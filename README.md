# Template

Template generator

- repo template
- package template
- file template 

## Install

- `npm create @jlbyte/repo`
	- `default (basic)`
	- `monorepo`
	- `library`
		- `default (js)`
		- `css`
	- `website`
		- `default (local)`
		- `vendor`
			- `default (cloudflare page)`
			- `cloudflare worker`
			- `render`
			- `@todo`
- `npm create @jlbyte/file` 
	- `default (README.md)`
	- `package.json (edit if exists)`
	- `tsconfig.json (override if exists)`
	- `babel.config (override if exists)`
	- `rollup.config (override if exists)`
	- `@todo`
